# Code de conduite

LoiCI est un projet civique. Il réunit des personnes de toutes opinions politiques autour d'un objectif commun :
rendre la loi ivoirienne accessible et vérifiable par tous. Ce code s'applique partout où le projet vit :
dépôt, issues, pull requests, discussions et tout espace qui le représente.

## Nos engagements

Nous nous engageons à faire de la participation à LoiCI une expérience respectueuse pour chacune et chacun,
quels que soient l'âge, l'origine, la région, l'ethnie, la religion, le genre, le handicap, le niveau d'études,
la profession, la langue parlée ou **l'opinion politique**.

## Ce que nous attendons

- **Discuter des faits, pas des personnes.** On critique une donnée, une source ou un code, jamais celui ou celle qui l'a proposé.
- **Prouver plutôt qu'affirmer.** Une correction s'appuie sur une source vérifiable, pas sur une conviction.
- **Rester neutre dans le projet.** Chacun garde ses opinions, mais elles n'entrent ni dans les données, ni dans les résumés,
  ni dans les échanges sur le dépôt. Nous ne faisons ni campagne, ni promotion, ni dénigrement d'un parti, d'un élu ou d'une institution.
- **Accueillir les débutants.** Beaucoup de contributeurs sont étudiants, journalistes ou citoyens qui découvrent GitHub :
  expliquez, montrez, ne moquez pas.
- **Accepter d'avoir tort.** Une source plus fiable l'emporte, d'où qu'elle vienne.

## Ce qui n'est pas acceptable

- les insultes, moqueries, propos discriminatoires ou haineux, y compris envers une communauté, une région ou un groupe politique ;
- le harcèlement, public ou privé, et l'intimidation ;
- la publication d'informations privées sur une personne (adresse, téléphone, famille…) sans son accord ;
- l'introduction volontaire de données fausses, invérifiables ou orientées ;
- l'utilisation du projet pour faire campagne ou pour attaquer une personne.

Les parlementaires, ministres et autres responsables publics sont décrits uniquement par leurs actes publics et sourcés.

## Signaler un problème

Si vous êtes victime ou témoin d'un comportement contraire à ce code, contactez en privé les mainteneurs du dépôt
(adresse de contact indiquée dans le README). Chaque signalement est traité avec discrétion ;
la personne qui signale est protégée de toute représaille.

## Ce qui peut se passer

Selon la gravité, les mainteneurs peuvent :

1. **rappeler** la règle, en privé ;
2. **avertir** publiquement et retirer le contenu en cause ;
3. **exclure temporairement** la personne des espaces du projet ;
4. **exclure définitivement** en cas de récidive ou de faute grave (harcèlement, menaces, désinformation délibérée).

Les mainteneurs peuvent modifier ou supprimer tout commentaire, commit, issue ou contribution contraire à ce code.

## Inspiration

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/), adapté aux exigences
de neutralité d'un observatoire législatif.
