# Lot 3 — Travail et protection sociale : tableau de suivi

Collecte du 17 novembre 2026. Numéros repérés par recherche web (sources secondaires), puis **chacun vérifié sur la
liste publique du CNDJ**, tous types de textes confondus (lois, ordonnances, décrets), 10 s entre deux requêtes.
Le recueil « Code du travail et autres textes » du CNDJ (72 textes) est réservé aux abonnés : il n'a pas pu être parcouru.

**Sous-catégories créées** : Code du travail · Prévoyance sociale et assurance maladie · Travail des enfants.

## À compléter

| Code de prévoyance sociale d'origine | Fiche | Le CNDJ intitule la loi n° 99-477 « portant modification du Code » : la loi qui a institué le Code n'est pas encore identifiée |

| Décret n° 2020-308 | Lien vers la loi qu'il applique | Son intitulé ne cite pas de loi ; une copie du JO (site de la CNPS) cite le Code de prévoyance sociale, mais ce site n'est pas dans les domaines officiels |
